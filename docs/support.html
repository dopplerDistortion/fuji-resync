camera setup

recipes over USB
MENU → SET UP → CONNECTION SETTING → PC CONNECTION MODE → USB RAW CONV./BACKUP RESTORE. Use a USB-C data cable no longer than 1.5 m.
photo map
Set PC CONNECTION MODE to USB CARD READER, then connect the cable. resync reads where each new photo was taken and pins it on the map.
geotags
MENU → NETWORK/USB SETTING → Bluetooth settings → pairing registration, then tap scan in resync. Turn on geotagging and location info on the camera. Allow location "always" on the phone to keep geotagging in the background.
remote
Open wireless communication on the camera, then tap connect in resync. The first time, accept the "resync" request on the camera.

common problems

the camera isn't found over USB
Check the PC connection mode above, and try another cable: many USB-C cables only charge.
photos aren't geotagged
Check that geotagging is on in the camera's Bluetooth settings, that resync shows the camera as linked, and that location access is set to "always" in iOS Settings → resync.
a recipe value was rejected
The write report lists the setting and the value that was sent. Please include it in an issue.

When you report a bug, the log tab can share the app's log, which helps a lot. It holds connection events, not your photos.
